Install App (Home Screen)

  1. Open the GitHub Pages website in Safari.
  2. Tap the Share button.
  3. Select Add to Home Screen.
  4. Edit the name if desired.
  5. Tap Add.
  6. Launch the archive from the new Home Screen icon.

Adding the website to the Home Screen creates a shortcut to the web app. It does not automatically install an IPA package.
